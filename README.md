# Alimentos Confiables Cortés — Landing page

Página de una sola pantalla con logo, descripción del negocio, carrusel de marcas, sucursales y botones de WhatsApp e Instagram.

Es un solo archivo, `index.html`, sin dependencias (los logos van incrustados). Para verla, ábrelo en el navegador.

## Publicar gratis
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Netlify o Cloudflare Pages:** conecta este repositorio; no necesita comando de build.

## Qué editar
- Textos, direcciones y enlaces: directamente en `index.html`.
- Número de WhatsApp: busca `wa.me/528148886103`.
